# Privacy Policy – Shared Memory Bot

Last updated: September 17, 2026

Shared Memory Bot is a university project designed to help users save and retrieve information through WhatsApp.

## Information We Process

When you interact with Shared Memory Bot, the application may process information you choose to send, including:

- WhatsApp text messages
- Links
- Saved content and metadata
- Your WhatsApp phone number or user identifier
- Automatically generated titles, summaries, categories, and tags

Future versions of the project may also support images, documents, and other media.

## How We Use Information

Information is processed only to provide the application's functionality, including:

- Saving content requested by the user
- Organizing saved content
- Generating searchable metadata
- Creating embeddings for semantic search
- Finding and returning previously saved information

## Third-Party Services

Shared Memory Bot currently uses third-party services to provide its functionality, including:

- Meta WhatsApp Business Platform for receiving and sending WhatsApp messages
- Supabase for database and storage services
- Google Gemini APIs for AI processing, enrichment, and embeddings

Information may be transmitted to these providers as necessary to provide the service.

## Data Storage

Saved items and associated metadata may be stored in Supabase.

The project is currently in development and should not be used to store highly sensitive or confidential information.

## Data Sharing

We do not sell user information.

Information is shared only with service providers required to operate the application, as described above.
